Sobre mim...

Quem é G. Olavo?

Sou estudante de Engenharia de Software pela UCSal e Técnico em Desenvolvimento de Sistemas pelo SENAI Bahia. Atualmente, tenho mergulhado nos meus projetos pessoais para colocar a teoria na prática. Meu foco principal tem sido o desenvolvimento back-end com Java, Spring Boot e MySQL, tentando cobrir tudo, desde rabiscar o modelo do banco até escrever o código da aplicação. Em paralelo, também venho estudando como elaborar protótipos e construir interfaces com HTML, CSS e JavaScript.
